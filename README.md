# Centro de Alto Rendimiento La Fábrica

Landing page (HTML, CSS y JS puros) del centro de entrenamiento de fútbol La Fábrica, Villa María del Triunfo, Lima Sur.

## Reemplazar fotos
Busca `FOTO` en `index.html`. Cada imagen de relleno (`placehold.co`) tiene un comentario encima indicando qué foto va y el tamaño sugerido.
Sube tus fotos a una carpeta `img/` y cambia el `src`, por ejemplo: `src="img/hero.jpg"`.

## WhatsApp
El número y el mensaje están al inicio del `<script>` (`WA_NUMBER` y `WA_MESSAGE`).
